# ScamShield
Phone-ready prototype for Global Innovation Hackathon 2026.

Participant: Avni Rajak
Institution: Baderia Global Institute of Engineering and Management, Jabalpur

## Features
- Message scanner
- Screenshot OCR scanner
- URL structure checker
- Explainable risk score
- Scam category inference
- Recommended safety action
- Mobile responsive UI

## Run
Upload index.html, style.css and app.js to GitHub and enable GitHub Pages (or another static host). The screenshot OCR uses Tesseract.js from a CDN, so internet access is needed for OCR.

## Note
The current demo uses transparent client-side rules plus OCR so it works without a private API key. It is a prototype risk-assessment tool, not a guarantee of safety or maliciousness.
